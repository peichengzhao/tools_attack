# Support

## Bugs and Reproducibility Issues

Open a GitHub issue and include:

- the command you ran;
- the relevant commit hash;
- the expected and actual behavior;
- the relevant portion of the log with secrets removed.

Use the issue templates when available.

## Security

Do not report credentials, private endpoints, or exploitable system details in a
public issue. Follow `SECURITY.md`.
