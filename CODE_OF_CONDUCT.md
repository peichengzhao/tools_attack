# Code of Conduct

## Our Pledge

We aim to make participation in this research repository a professional,
harassment-free experience for everyone, regardless of background, identity, or
experience level.

## Expected Behavior

- Discuss technical disagreements with evidence.
- Reproduce claims before escalating them.
- Remove credentials and sensitive data from logs.
- Respect responsible-disclosure and authorized-use requirements.
- Give credit for code, data, and research artifacts.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing credentials or private data.
- Encouraging unauthorized use of attack artifacts.
- Misrepresenting experimental provenance or results.

## Enforcement

Maintainers may remove comments, close issues, or restrict participation when
behavior violates this code. Concerns can be raised privately through the
repository maintainers' GitHub contact.

This code is adapted from the Contributor Covenant, version 2.1.
